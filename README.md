## Корпус писем Николая Эрдмана и Ангелины Степановой

## Описание датасета

Предложенный для работы датасет представляет собой корпус писем Николая Эрдмана и Ангелины Степановой. Также исходный датасет включал в себя воспоминания Ангелины Степановой, которые были в дальнейшем удалены, т.к. целью практики была подготовка датасета для количественного анализа текстовых данных исключительно из писем. 

## Источник данных

Источником данных является текстовый файл `erdman.txt`, содержащий письма Николая Эрдмана и Ангелины Степановой, а также воспоминания А. О. Степановой.

Для обработки использовались следующие библиотеки Python:

- `re` — регулярные выражения для очистки текста и извлечения дат;
- `pandas` — создание и структурирование итоговой таблицы;
- `razdel` — токенизация текста;
- `pymorphy3` — морфологический анализ и лемматизация слов;

## Структура датасета

Итоговый датасет содержит следующие столбцы:
1) `дата` - дата письма, извлечённая из заголовочной части текста. 
2) `автор` - адресант письма: Николай Эрдман или Ангелина Степанова. 
3) `текст письма` - полный текст письма после предварительной очистки. 
4) `лемматизированный текст письма` - текст письма, в котором слова приведены к начальной форме. 
5) `количество слов в письме` - число слов в письме после токенизации. 

Каждая строка датасета соответствует отдельному письму.

## Методы извлечения и обработки данных

### 1. Загрузка исходного текста
Исходный файл `erdman.txt` считывается средствами Python с указанием кодировки UTF-8.

### 2. Очистка и разделение текста
Для предварительной обработки используются регулярные выражения. Удаляются сноски вида [число], лишние пробелы и повторяющиеся пустые строки.
Далее текст разделяется на отдельные блоки по разделителю `* * *`. Текстовые блоки, содержащие заголовок `[Воспоминания А. И. Степановой]`, выделяются отдельно и удаляются из датасета. Остальные блоки определяются как письма и сохраняются в датасет.

### 3. Извлечение дат
Для поиска дат используются регулярные выражения, учитывающие различные варианты записи: числовой формат, полные и сокращённые названия месяцев, а также названия месяцев без указания числа. 

### 4. Определение авторства
Адресант письма определяется по подписи или по обращениям, содержащимся в заголовочной части текста. В том случае, если в заголовочной части текстового блока отсутствует указание имени автора письма, адресант устанавливается по обращению в конце текстовго блока (например, если в конце стоит подпись "А.О. Степановой", автором письма присваивается автор Эрдман). 

### 5. Лемматизация
Текст каждого письма токенизируется с помощью библиотеки `razdel`. Для каждого токена, состоящего из букв, с помощью `pymorphy3` определяется начальная форма слова. В результате для каждого письма формируется отдельный лемматизированный текст и сохраняется в отдельный столбец датафрейма. 

### 6. Подсчёт количества слов
Количество слов рассчитывается на основе токенизации. Учитываются только токены, состоящие из букв, числа и знаки препинания не включаются в подсчёт.

## Работа с отсутствующими значениями дат
Даты в исходных письмах записаны неоднородно: встречаются разные форматы, сокращённые названия месяцев, а также указания только на месяц без конкретного числа.
Если дату не удаётся извлечь из заголовка письма, для соответствующей записи сохраняется отсутствующее значение (`None`). При экспорте в CSV такие значения могут отображаться как пустые ячейки.

## Формат публикации
Итоговый датасет публикуется в формате CSV. Файл содержит структурированную таблицу, пригодную для дальнейшей обработки и анализа данных через Python.
Итого найдено 55 дат, 29 писем атрибутированы как письма А.О. Степановой, 27 - как письма Н. Эрдмана.
